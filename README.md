# Custom Piko NewX Patches

Custom Morphe patches for X (NewX `12.43.0-prod.01`):

- **Home timeline gear button** (`HomeTimelineGearPatch.kt`): Places a `32dp` gear icon in the top-right corner of the Home bar (replacing the Premium upsell) that opens the custom timelines picker, while leaving the `+` button on the custom timelines bar intact.
- **Drawer Piko settings icon** (`DrawerPikoSettingsIconPatch.kt`): Adds a Piko Settings gear icon to the bottom-right corner of the side navigation drawer.

> Note: Enable Crimera's official Piko NewX bundle alongside this source in Morphe Manager so Piko Settings itself is included.
